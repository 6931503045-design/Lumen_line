## ปุ่มที่ใช้ตอนพรีเซนต์

| ปุ่ม | ทำอะไร |
|---|---|
| `→` `Space` `PgDn` | สไลด์ถัดไป (รีโมตพรีเซนต์ใช้ได้) |
| `←` `PgUp` | ย้อนกลับ |
| `1`–`5` | กระโดดไปต้นส่วนของผู้พูดคนที่ 1–5 |
| `S` | เปิดหน้าต่างผู้พูด: บทพูด + สไลด์ถัดไป + นาฬิกา (ลากไปไว้จอโน้ตบุ๊ก) |
| `N` | บทพูดใต้จอ (ถ้าไม่ได้ต่อจอสองจอ) |
| `T` | เริ่มนาฬิกาใหม่จาก 0:00 |
| `B` | จอดำ ตอนสลับไปเดโมของจริง |
| `R` | เล่นแชทจำลองในสไลด์นั้นใหม่ |
| `M` | เริ่ม/หยุดแชร์จอมือถือสดขึ้นสไลด์ 4, 5, 9 (หรือกดปุ่ม 📱 มุมขวาบน) |
| `O` | ภาพรวมทุกสไลด์ |
| `L` | สลับภาษาไทย / อังกฤษ (หรือกดปุ่ม TH/EN มุมขวาบน) |
| `F` | เต็มจอ |
| `?` | ดูปุ่มลัดทั้งหมด |

## แชร์จอมือถือขึ้นสไลด์ (iPhone + Windows)

จอ iPhone จะไปโผล่ในกรอบโทรศัพท์ของสไลด์ 4, 5 และ 9 แบบสด ๆ เลือกหน้าต่างครั้งเดียว ใช้ได้ทั้ง 3 สไลด์

1. ลงแอป **LetsView** (ฟรี เป็นตัวรับ AirPlay) บนโน้ตบุ๊ก Windows
2. ต่อ iPhone กับโน้ตบุ๊กเข้า **Wi-Fi เดียวกัน** — Wi-Fi มหาลัยมักบล็อก AirPlay ให้เปิด hotspot จากมือถืออีกเครื่องแล้วต่อทั้งคู่แทน
3. บน iPhone: Control Center → **Screen Mirroring** → เลือกชื่อโน้ตบุ๊ก
4. เปิด `index.html` ด้วย Chrome/Edge → ไปสไลด์ 4 → กด `M` → แท็บ **Window** → เลือกหน้าต่าง LetsView → Share
5. จบเดโมกด `M` อีกครั้ง (หรือ "Stop sharing" ที่แถบของ Chrome) สไลด์จะกลับเป็นแชทจำลองเอง

ข้อควรรู้: ต้องกด `M` ที่หน้าต่างสไลด์ ไม่ใช่หน้าต่างผู้พูด (`S`) · ซ้อมก่อนวันจริงอย่างน้อยหนึ่งรอบ · ถ้าแชร์ไม่ติด สไลด์ยังมีแชทจำลองเหมือนเดิม

## แผนสำรองถ้าเดโมสดล่ม

- **บอทไม่ตอบ:** สไลด์ 4 และ 9 มีแชทจำลองที่เล่นเอง กด `R` หรือคลิกที่หน้าจอโทรศัพท์เพื่อเล่นใหม่ ในสไลด์ 4 คลิกขั้น 1/2/3 เพื่อเล่นเฉพาะขั้นนั้นได้
- **เว็บเปิดไม่ขึ้น:** สไลด์ 5 มีภาพหน้าจอ 4 หน้า คลิกทีละภาพเพื่อซูม
