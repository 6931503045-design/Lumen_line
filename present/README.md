# สไลด์ Final Demo — JOD tang (ทีม Lumen)

เปิด `index.html` ด้วย Chrome หรือ Edge ได้เลย ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้องติดตั้งอะไร
ถ้าไม่มีเน็ต ฟอนต์จะเปลี่ยนเป็นฟอนต์ไทยของเครื่องแทน ส่วนอื่นใช้ได้ครบ

## ปุ่มที่ใช้ตอนพรีเซนต์

| ปุ่ม | ทำอะไร |
|---|---|
| `→` `Space` `PgDn` | สไลด์ถัดไป (รีโมตพรีเซนต์ใช้ได้) |
| `←` `PgUp` | ย้อนกลับ |
| `1`–`5` | กระโดดไปต้นส่วนของผู้พูดคนที่ 1–5 |
| `S` | เปิดหน้าต่างผู้พูด: บทพูด + สไลด์ถัดไป + นาฬิกา (ลากไปไว้จอโน้ตบุ๊ก) |
| `N` | บทพูดใต้จอ (ถ้าไม่ได้ต่อจอสองจอ) |
| `T` | เริ่มนาฬิกาใหม่จาก 0:00 |
| `B` | จอดำ ตอนสลับไปเดโมของจริง |
| `R` | เล่นแชทจำลองในสไลด์นั้นใหม่ |
| `O` | ภาพรวมทุกสไลด์ |
| `L` | สลับภาษาไทย / อังกฤษ (หรือกดปุ่ม TH/EN มุมขวาบน) |
| `F` | เต็มจอ |
| `?` | ดูปุ่มลัดทั้งหมด |

นาฬิกาเริ่มเองตอนกดออกจากสไลด์แรก และเปลี่ยนเป็นสีส้มเมื่อเกินเวลาของผู้พูดคนนั้น
