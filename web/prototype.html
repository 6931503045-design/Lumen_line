ทางที่ผิด (empty / error state)

เกณฑ์ขอให้มีทางที่ผิดด้วย ไม่ใช่แค่ happy path — กดแต่ละแถวเพื่อเปิดดูได้จริง หรือเปิดทุกหน้าแบบ ผู้ใช้ใหม่ที่ยังไม่มีข้อมูล →

ว่างผู้ใช้ใหม่ยังไม่มีรายการ (ภาพรวม)"ยังไม่มีข้อมูล" + ชวนพิมพ์รายการแรก ไม่ใช่ ฿0 ว่างผู้ใช้ใหม่ยังไม่มีรายการ (รายการ)"ยังไม่มีรายการ — พิมพ์ในแชท LINE เช่น กาแฟ 80" ว่างยังไม่ได้ตั้งงบสักหมวด"ยังไม่ตั้งงบ" ไม่ใช่ 0% ว่างยังไม่มีแผนออมปุ่ม "+ สร้างแผนเก็บเงินแรก" ว่างข้อมูลน้อยกว่า 7 วัน"ข้อมูลยังไม่เพียงพอ" ไม่เดาตัวเลขลอย ๆ ผิดแชท: พิมพ์ไม่มียอด / ยอดเป็น 0การ์ด "อ่านข้อความไม่ออก" + ตัวอย่าง ผิดกรอกยอดเป็น 0 ในฟอร์มเพิ่ม/แก้รายการไม่บันทึก + "กรุณาใส่จำนวนเงินมากกว่า 0" ผิดลบหมวดที่ยังมีรายการอยู่ปฏิเสธ + บอกจำนวนรายการ
ผิดยังไม่ได้ล็อกอิน / เซสชันหมดอายุ (เว็บจริง)หน้า "เข้าสู่ระบบด้วย LINE" + ปุ่มดูตัวอย่าง
