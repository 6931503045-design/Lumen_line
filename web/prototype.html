ทางที่ผิด (empty / error state)

เกณฑ์ขอให้มีทางที่ผิดด้วย ไม่ใช่แค่ happy path — ทุกสถานะด้านล่างมีอยู่จริงในโค้ด

ว่างผู้ใช้ใหม่ยังไม่มีรายการ"ยังไม่มีรายการ" ไม่ใช่ ฿0.00
ว่างยังไม่ได้ตั้งงบสักหมวด"ยังไม่ได้ตั้งงบ" ไม่ใช่ 0%
ว่างยังไม่มีแผนออมชวนกด "สร้างแผนใหม่"
ผิดยังไม่ได้ล็อกอินแถบเหลือง + ปุ่มเข้าสู่ระบบ
ผิดเซสชันหมดอายุแถบแดง + ให้ล็อกอินใหม่
ผิดกรอกยอดเป็น 0ปฏิเสธ + บอกให้ใส่มากกว่า 0
ผิดลบหมวดที่ยังมีรายการอยู่ปฏิเสธ + บอกจำนวนรายการ
